# Security Policy

## Supported versions

Security fixes are applied to the latest development version before a stable release is available.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could affect users. After the GitHub repository is created, use its private security advisory flow and include reproduction steps, affected Windows version, and the smallest safe proof of concept.

PulseMouse installs a global mouse hook and can send input. Reports involving unintended input, privilege boundaries, configuration import, or arbitrary command execution are security-sensitive.
