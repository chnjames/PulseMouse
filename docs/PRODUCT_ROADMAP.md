# PulseMouse 产品路线图

> 编写日期：2026-10-13，基于 v0.8（提交 `718111c`）。竞品信息来自公开网页，访问日期同上，需定期复核。

## 1. 结论

- **技术可行**：v0.8 已完成节奏识别、方向手势、工作流、状态胶囊和完整设置，Release 构建与冒烟测试通过。
- **不宜做成通用效率工具**：在「快速打开程序/文件/网址」这件事上，Quicker、Raycast、PowerToys、Logitech Actions Ring 动作更多、无需记忆，PulseMouse 正面竞争没有优势。
- **差异化在「盲操作」**：光标不动、不看屏幕，敲一下节奏就执行。适合每人最高频的 3–8 个动作。
- **定位**：鼠标上的快捷键——为已有工具提供一层盲操作触发器，而不是替代它们。
- **前提**：先解决两个门槛——唤醒摩擦（第 6 节）和记忆负担（第 7.2 节），再用小范围测试验证留存（第 8 节）。

## 2. 现状（v0.8）

| 能力 | 状态 |
|---|---|
| 节奏输入 | 短按 `·` / 长按 `—`，最多 5 位，停顿 750 ms 提交 |
| 唤醒方式 | 侧键直接敲（X1/X2/自动）或中键静止长按 550 ms 后用左键敲 |
| 动作类型 | 打开程序、打开文件夹、打开 HTTPS 网址、工作流（最多 12 步） |
| 方向手势 | 按住中键上下左右拖动，4 个方向 |
| 反馈 | 屏幕状态胶囊、仪表盘实时节奏、诊断日志 |
| 数据 | 本地 JSON，可导出/导入；统计今日执行、今日未匹配、本周运行时长 |

已知问题（来自 `src/PulseMouse.Windows/MouseHook.cs`）：

- 侧键模式拦截选中侧键的每一次按下，后退/前进失效；自动模式在首次按到侧键时永久接管该键。
- 中键按下/抬起原样透传，长按会触发浏览器自动滚动，在链接上松开会新开标签页。
- 中键激活后 7 秒内左键全部被当作节奏输入。
- 输入一条 `··` 需要约 1.6–2 秒（长按 550 ms + 两次点击 + 停顿 750 ms）。
- 没有中键或侧键的设备（触控板）无法使用。

## 4. 优势与短板

**优势**

1. **盲操作**：面板类工具要求「弹出 → 看 → 移动光标 → 点击」；PulseMouse 光标原地不动，熟练后对最高频动作更快、更少打断注意力。
2. **不挑硬件**：改为和弦唤醒后，任意双键鼠标可用（Actions Ring 需要罗技设备）。
3. **轻量、本地、无账号**：配置不上传，装好即用。
4. **有记忆点**：节奏像「暗号」，演示效果好；适合老板键、静音、锁屏、隐藏窗口等需要不动声色的动作。
5. **界面完成度**：实时节奏可视化、状态胶囊、冲突检测，在同类小工具中较精致。

**短板**

1. **记忆负担**：`.-.` 与 `-..` 对新用户没有含义；普通人实际能记住 5–8 个。
2. **唤醒摩擦**：见第 2 节已知问题。
3. **动作类型少**：缺少发送快捷键、粘贴文本、媒体/音量、窗口操作、按应用切换。
4. **信任与兼容**：全局鼠标钩子易被杀毒软件误报；游戏反作弊；对管理员权限窗口无效；未签名 exe 难以让陌生用户放心安装。
5. **难解释**：一句话说不清，需要短视频演示。

## 5. 产品定位

**一句话**：PulseMouse 是鼠标上的快捷键——敲一下节奏，不看屏幕就能执行你最常用的几件事。

**目标用户**

- 主要：以鼠标为主的办公和创作用户，已经在用 Quicker / Raycast / AutoHotkey，希望最高频的几个动作再快一点。
- 次要：喜欢新奇交互、愿意尝鲜的效率工具爱好者（传播种子用户）。
- 暂不考虑：游戏玩家（反作弊风险）、单开关无障碍用户（需要另做键盘与光标输入，视为独立方向，见第 10 节）。

**原则**

- 做触发层，不做动作平台：用户已有的工具（Quicker 动作、AutoHotkey 脚本、网址、程序）都应能被节奏触发。
- 原生行为不受损：任何按键在没有用于节奏时，必须保持原有功能。
- 新手看得见，熟手不用看：同一套节奏既能查看提示，也能盲敲。

## 6. 唤醒方式改造：和弦式唤醒

### 6.1 交互

1. 按住触发键（默认右键）。
2. 用左键敲 `·` / `—`。
3. 松开触发键立即提交，不再等待 750 ms 停顿。

- 第一次按下左键时才显示状态胶囊，普通右键单击不闪胶囊。
- 按住期间按 Esc 或滚动滚轮，取消本次输入。

### 6.2 保留原生功能（延迟决策）

触发键按下时先扣住，满足以下任一条件时再处理：

| 情况 | 处理 |
|---|---|
| 未按左键就松开触发键 | 立即补发一次完整单击（右键菜单正常弹出，仅延迟按住的时长） |
| 按住时鼠标移动超过约 8 px，且尚未按左键 | 立即补发触发键按下，之后全部放行（右键拖拽、地图平移、游戏不受影响） |
| 按住超过约 600 ms 仍未按左键 | 同上，补发并放行 |

### 6.3 触发键选项

- 右键（默认）。
- X1 / X2：规则相同，单击仍为后退/前进。
- 中键：规则相同，单击仍能开标签/关标签，长按不再触发自动滚动；中键拖动仍为方向手势。
- 经典模式（保留）：中键长按 + 左键；侧键直接敲（界面明确提示会失去后退/前进）。

### 6.4 保护措施

- 应用排除列表：按前台进程名匹配，在列表内完全不拦截。
- 全屏自动暂停：检测到全屏游戏或演示时暂停拦截。
- 管理员权限窗口：普通权限程序补发的输入会被 Windows 拦截，因此对这类前台窗口直接放行。
- 忽略自身补发的事件，避免与其他钩子工具形成循环。

### 6.5 时间对比

| 方式 | 输入 `··` 的大致耗时 |
|---|---|
| 中键长按 + 左键（现状） | 1.6–2 s |
| 侧键直接敲（现状） | 约 1.0 s |
| 和弦唤醒 | 约 0.5 s |

## 7. 路线图

规模为相对估计：小（数天内）、中（约一周）、大（一周以上）。

### 阶段 1：和弦唤醒（规模：大）

- 范围：第 6 节全部内容；经典中键模式同步修复自动滚动问题。
- 涉及模块：
  - `MouseHook`：延迟决策、`SendInput` 补发、忽略自身注入事件。此前约定不改动该模块，本阶段需要明确放开。
  - Core：新增可单测的 `ChordActivation`（写法参照 `MiddleActivation`）；`RhythmEngine` 增加公开的立即提交方法，识别逻辑不变。
  - 配置：输入方式新增「和弦」、触发键、排除列表；旧配置保持原输入方式，新安装默认和弦。
  - 界面：仪表盘「输入方式」卡片改为选择触发键 + 经典模式入口；设置页新增排除列表。
- 验收：
  - 右键单击、右键拖拽、长按右键在资源管理器、浏览器、Office 中行为与未安装时一致。
  - 和弦输入 `··` 从松开触发键到动作发起小于 100 ms。
  - 单元测试覆盖：单击补发、移动补发、超时补发、和弦输入、松开提交、忽略自身注入、排除列表。

### 阶段 2：降低记忆负担（规模：中）

- **犹豫就提示**：唤醒后停顿超过约 0.6 s，在胶囊旁显示当前可用节奏清单（新手看清单，熟手直接敲）。
- **节奏建议**：新建指令时按名称首字母的摩尔斯码给出建议节奏（如 Notepad → N → `-.`），并检查冲突。
- **练习模式**：在仪表盘随机出题，记录正确率。
- 验收：新用户无需打开主窗口即可完成全部已绑定指令。

### 阶段 3：扩展动作类型与外部工具（规模：中）

- 新增动作：发送快捷键、粘贴文本片段、媒体与音量、窗口置顶/最小化/关闭、锁屏、静音。
- 外部工具：
  - Quicker 动作链接（Quicker 中可复制动作 URI）；
  - AutoHotkey 脚本（以程序方式启动）；
  - Raycast 深度链接（Windows 版是否支持需确认）。
- 工作流步骤同步支持新动作类型；工作流 JSON 保持向后兼容（旧的 `Kind` 0/1/2 不变，新类型追加）。
- 验收：每种新动作有冒烟测试；旧配置导入后行为不变。

### 阶段 4：按应用切换指令集（规模：中）

- 指令可设置「全局」或「仅在某应用中」；同一节奏在不同应用中可绑定不同动作。
- 冲突检测按作用范围计算。
- 验收：前台应用切换后无需重启即生效；全局指令在没有专属绑定的应用中照常工作。

### 阶段 5：发布准备（规模：中）

- 代码签名、安装包（含开机自启动选项）、自动更新检查。
- 首次启动引导：选择触发键 → 绑定 3 个推荐动作 → 练习一次。
- 30 秒演示视频、产品页。
- 统计：增加按日保存的本地历史（目前「今日执行」「今日未匹配」每天清零），供第 8 节测试导出，数据仅保存在本机。

## 8. 验证计划

在阶段 1、2 完成后、阶段 3 开始前进行。

**方法**

1. 招募 5–10 名目标用户，每人配置 5 个节奏，使用一周。
2. 第 1 天与第 7 天各做一次无提示回忆测试。
3. 对同一动作分别用 PulseMouse、Quicker 面板（或开始菜单搜索）完成，记录耗时。
4. 收集本地统计（每日执行次数、未匹配次数）与简短访谈。

**指标**

| 指标 | 目标 |
|---|---|
| 第 7 天人均每日执行次数 | ≥ 5 |
| 未匹配率（未匹配 / 全部尝试） | ≤ 10% |
| 第 7 天回忆正确数（满分 5） | ≥ 4 |
| 第 7 天仍在使用的人数比例 | ≥ 60% |

**停止或转向条件**

若一周后人均每日执行少于 3 次，或未匹配率高于 15%，说明节奏本身吸引力不足：停止扩展节奏功能，把重心转向「触发器层 + 方向手势」。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 补发输入导致右键菜单延迟或错位 | 补发在触发键松开时立即执行；移动超阈值即放行；验收覆盖主流应用 |
| 游戏反作弊误判 | 全屏自动暂停 + 排除列表；默认不建议在游戏中使用 |
| 杀毒软件误报全局钩子 | 代码签名；文档说明钩子用途；不联网 |
| 与 Quicker、StrokesPlus 等工具争抢同一按键 | 忽略模拟输入；文档说明启动顺序与按键分配 |
| 管理员权限窗口中无效 | 检测到后放行，并在诊断日志中说明 |
| 功能膨胀，失去「简单」 | 坚持触发层定位；复杂逻辑交给外部工具 |

## 10. 待决策

1. **默认触发键**：右键（推荐，所有鼠标都有）还是 X2。
2. **是否放开 `MouseHook` 改动**：阶段 1 必须修改其逻辑。
3. **无障碍方向**：单开关摩尔斯输入有真实需求，但需要键盘输入与光标控制，建议验证主线后再评估。
4. **分发与商业模式**：免费 / 开源 / 买断。同类工具多为免费，建议先免费积累用户。
