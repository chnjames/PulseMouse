# PulseMouse v0.7 — V3 Liquid Glass

## 设计稿梳理

三个 HTML 原型中，`PulseMouse-V3.html` 是功能和视觉最完整的目标稿；`PulseMouse-UI-Redesign.html` 与 `PulseMouse-LiquidGlass.html` 属于其前序方案。

V3 的核心视觉结构：

- 48px 自绘标题栏、230px 左侧导航、固定底部 Pulse Capsule。
- 黑色半透明底层、低对比玻璃面板、薄荷青输入状态、冰蓝统计强调。
- 仪表盘采用“统计摘要 → 输入引擎 → 实时节奏与输入方式 → 事件流”的纵向信息层级。
- 指令页采用列表—详情布局，并提供点/划可视化节奏编辑。
- 设置页采用分组行，而不是把每个选项做成独立卡片。

## 已实现功能

- 今日执行次数、已绑定指令、本周活跃时长统计。
- 可视化添加短按、长按与清空节奏，仍支持键盘直接编辑。
- Windows 当前用户开机自启动。
- 指令成功发起后的系统提示音。
- 中文/English 偏好持久化，并切换主要导航、页标题与副标题。
- Pulse Capsule 左下、居中、右下三种位置。
- Pulse Capsule 呼吸动画开关。
- 完整配置 JSON 导出与导入；导入后安全退出并要求重新启动。
- 旧版 v0.6 JSON 配置兼容，新增字段使用安全默认值。

## 实现边界

- 语言切换覆盖主要导航与页面标题；既有诊断消息、系统异常和部分表单文案仍保留中文。
- 开机自启动写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，不需要管理员权限。
- “今日执行次数”在动作成功发起后计数；它不代表目标程序最终完成了内部任务。
- “本周活跃时长”统计 PulseMouse 进程的运行时长，不是用户实际操作鼠标的时长。
