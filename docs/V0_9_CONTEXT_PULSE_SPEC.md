# PulseMouse v0.9 · Context Pulse 迭代说明

> 编写日期：2026-10-14。对照基线：提交 `a3e1843`（v0.8 + 未发布改动，见 `CHANGELOG.md`）。
> 效果图：[`docs/design/PulseMouse-v0.9-Context-Pulse.html`](design/PulseMouse-v0.9-Context-Pulse.html)（双击用浏览器打开）。本文与效果图不一致时，以本文为准。

## 1. 一句话

同一个节奏，在不同程序里可以有不同含义：按下右键那一刻光标在哪个程序上，就用那个程序的含义；没有定义就用全局含义；到哪都要用的动作被“固定”，任何程序都不能改。

## 2. 设计决策（已确认）

| 决策 | 结论 | 理由 |
|---|---|---|
| 情境如何判定 | 按下触发键那一刻**光标下窗口**所属的程序 | 盲操作时用户指着哪里，就是想操作哪里；不依赖键盘焦点 |
| 同一节奏能否在不同程序有不同含义 | **能** | 最顺手的短节奏只有 6 个（1 位 2 个、2 位 4 个），每个程序都应该能用 |
| 如何避免“在某程序里丢掉必须的全局动作” | **固定**：系统级动作默认固定，任何程序不能改它的节奏 | 冲突只在“到哪都要用”的动作上才有害 |
| 被替换的全局含义如何临时找回 | **不提供**（已否决“停住 0.7 秒切回”和“按住 Shift”） | 有了固定后需求基本消失；隐藏交互违背简单原则；Shift 违背“不碰键盘” |
| “意图模型”（一个节奏只对应一个意图） | **否决** | 程序独有的功能会被迫使用更长的节奏，记忆负担更大 |
| 改了含义如何让用户知道 | 节奏地图 + 胶囊显示程序 + 前 5 次“新含义提醒” | 防止跨程序敲错 |
| 快捷键发到哪里 | 发送前**激活光标下的窗口** | 现状发到前台窗口，与“指着哪里操作哪里”不一致 |

## 3. 术语

| 术语 | 含义 |
|---|---|
| 全局含义 | 作用范围为空的指令；所有程序的默认含义 |
| 程序含义 | 作用范围为某个进程名的指令；只在光标位于该程序窗口时生效 |
| 替换 | 程序含义使用了某条非固定全局指令的节奏；在该程序中取代全局含义 |
| 专属 | 程序含义使用的节奏在全局没有指令 |
| 固定 | 全局指令的属性；固定的节奏在所有程序中都是这条全局含义，不能被程序含义使用 |
| 程序列表 | 用户添加过的程序；决定节奏地图有哪些列，独立于指令保存 |
| 情境 | 本次输入所属的程序（进程名），在按下触发键时确定 |
| 新含义提醒 | 替换型程序含义的前 5 次成功执行，胶囊额外提示“这里是新含义 · 全局是什么” |

## 4. 变化总览（现状 → v0.9）

| 范围 | 现状（v0.8 + 未发布） | v0.9 |
|---|---|---|
| 指令模型 | `CommandBinding` 只有 名称/节奏/类型/目标；节奏全局唯一 | 新增 Id、作用范围（进程名）、固定、提醒剩余次数、最后使用时间与程序；节奏在同一作用范围内唯一 |
| 节奏匹配 | `RhythmEngine` 用 `Commands.FirstOrDefault(c => c.Pattern == pattern)` | 引擎只输出节奏；由新的 `ContextResolver` 按“固定 → 程序 → 全局”解析 |
| 情境 | 无 | 触发键按下时记录光标下窗口句柄与进程名 |
| 快捷键目标 | 发给当前前台窗口 | 先激活情境窗口，再发送 |
| 动作类型 | 程序、文件夹、网址、工作流、快捷键 | 新增“重复上一次”（`ActionKind.Repeat = 5`） |
| 冲突检测 | `ConflictName`：全局同节奏即冲突 | 按作用范围计算；固定节奏禁止程序使用；替换给出警告；冲突时推荐 3 个空闲节奏 |
| 指令库界面 | 搜索 + 列表 + 右侧编辑栏 | “节奏地图 / 列表”两种视图 + 编辑栏（新增作用范围、固定、各程序含义、使用热度）+ 程序增删 + 模板 |
| 犹豫提示 | 列出全局所有以前缀开头的指令 | 列出当前程序实际可用的含义，并标注 专属 / 替换「X」/ 固定 |
| 胶囊 | 显示节奏与指令名 | 增加情境行：“Chrome 中的含义 / 全局 · 固定 / 全局 · 在 Excel”；新含义提醒时琥珀色 |
| 仪表盘 | 今日执行 / 已绑定指令 / 本周运行时长；候选为全局 | 统计卡改为 今日执行 / 在用的节奏 / 有专属含义的程序；实时节奏显示“光标在 X”；候选按情境解析；最近执行标注程序 |
| 统计 | `CommandsToday` 与 `History` 按指令**名称**计数 | 按指令 **Id** 计数；新增最近 7 天热度、最后使用时间与程序 |
| 设置 | 通用 / 鼠标拦截 / 节奏识别 / 胶囊 / 安全与数据 / AI 入口 | 新增“情境”分组（4 个开关） |
| 模板 | 无 | 浏览器模板（Chrome、Edge），逐条确认 |
| 配置版本 | SchemaVersion 8 | SchemaVersion 9，自动迁移 |
| 方向手势、工作流编辑器 | — | 界面**不变**；工作流保存时的冲突检测改用新规则（见 5.12 其他） |

## 5. 功能规格

### 5.1 情境判定

1. 在触发键按下的那一刻确定情境，本次输入期间不再改变（松开前把光标移到别的窗口不影响）。
   - 右键和弦：右键按下时。
   - 侧键直敲：侧键第一次按下时。
   - 中键长按：中键按下时。
2. 取光标位置的窗口：`WindowFromPoint` → `GetAncestor(GA_ROOT)`，记录**根窗口句柄**与**进程名**（小写、去掉 `.exe`，规则同 `MouseHook.NormalizeAppName`）。
3. 桌面与任务栏：窗口类为 `Progman`、`WorkerW`、`Shell_TrayWnd`、`Shell_SecondaryTrayWnd` 时，情境为“桌面”，**只使用全局含义**。资源管理器文件窗口（同为 `explorer.exe`）仍按进程 `explorer` 处理。
4. 情境无法取得（窗口已销毁、无权限读取进程名）时按“桌面”处理。
5. “按程序切换含义”关闭时，任何情境都只用全局含义（程序含义保留不删）。
6. 方向手势不使用情境（v0.9 不做按程序区分手势）。

### 5.2 解析规则

```
Resolve(pattern, context):
  g = 全局指令中 Pattern == pattern 的那条
  if g != null && g.Pinned           → g
  if 按程序切换开启 && context 不是桌面:
      a = 作用范围 == context 且 Pattern == pattern 的那条
      if a != null                   → a
  if g != null                       → g
  → 未匹配
```

- 解析放在 Core，纯函数，可单测。
- 未匹配时胶囊与日志写明程序：“Chrome 中没有 ·—·”。
- 犹豫提示与仪表盘候选使用同一套解析：列出 `Resolve` 后可达的结果，按节奏长度、再按 `·` 在 `—` 前排序，最多 6 条，其余显示“另有 N 条”。

### 5.3 固定

1. 只有全局指令有“固定”属性。
2. 新建或修改全局指令时，**未手动改过固定开关**的，按下表自动设定：

| 自动固定 | 不固定 |
|---|---|
| 类型为 程序 / 文件夹 / 网址 / 工作流 / 重复上一次 | 其他快捷键（复制、粘贴、撤销、关闭标签、刷新等作用在程序内部的） |
| 快捷键为：`Alt+Tab`、`Win+Tab`、`Win+D`、`Win+E`、`Win+L`、`Shift+Win+S`（含 `Win+Shift+S` 写法）、`VolumeMute`、`VolumeUp`、`VolumeDown`、`MediaPlayPause`、`MediaNextTrack`、`MediaPrevTrack` | |

3. 用户可在编辑栏手动开关“固定：在所有程序中保持不变”，之后不再自动改。
4. 打开固定时，若已有程序含义使用该节奏，阻止保存并提示：“Excel 中是「重复上一步」；要固定需先移除这些程序含义”。
5. 删除一条固定的全局指令后，该节奏在各程序中解锁。

### 5.4 冲突与校验

编辑栏节奏输入下方的提示，按优先级：

| 情况 | 级别 | 文案示例 | 能否保存 |
|---|---|---|---|
| 未输入 | 提示 | 点击添加短按 · 或长按 —，最多 5 位 | 否 |
| 同一程序已有该节奏 | 错误 | Chrome 中这个节奏已经是「刷新」 | 否，给出 3 个推荐 |
| 程序含义使用固定节奏 | 错误 | 「切换窗口」已固定，在所有程序中保持不变 | 否，给出 3 个推荐 |
| 程序含义替换非固定全局 | 警告 | 在 Chrome 中替换全局「复制」；其他程序不受影响 | 能 |
| 程序含义使用空闲节奏 | 通过 | Chrome 中可用；其他程序里这个节奏没有含义 | 能 |
| 全局已有该节奏 | 错误 | 已被全局「复制」占用 | 否，给出 3 个推荐 |
| 全局节奏在某些程序中被替换 | 通过 | 可用；Excel 中是「重复上一步」 | 能 |

- **推荐空闲节奏**：按 1 位 → 4 位、同长度 `·` 优先的顺序，取前 3 个满足“全局未使用，且（程序含义时）该程序未使用”的节奏，点击即填入。
- **修改全局指令的节奏**时，若旧节奏在某些程序中被替换，保存时提示：“Excel 中的「重复上一步」仍在 —，它会变成 Excel 专属”。程序含义绑定在节奏上，不跟随全局指令移动。
- 其余校验（名称必填、目标合法、最多 5 位）保持现状。

### 5.5 程序管理

- **程序列表单独保存**（`ContextApps`），不从指令推算。程序最后一条含义被移除后，列仍保留。
- **添加程序**：弹窗列出
  - 当前运行中的有窗口程序（排除 PulseMouse 自身和系统进程）与最近出现过的情境程序，标注“运行中 / 最近使用 / 已添加”；
  - “拾取窗口”：3 秒内把光标移到目标窗口上，读取其进程名；
  - “浏览 .exe…”：选择可执行文件，取文件名作为进程名。
  - 显示名默认取可执行文件的文件描述（`FileVersionInfo.FileDescription`），取不到用进程名。图标取可执行文件图标。
- **移除程序**：节奏地图列标题右侧 “×” 与列表视图分组标题的“移除”。弹出确认框，逐条列出将删除的含义及删除后的结果（“→ 全局「关闭标签页」”或“→ 无含义”）。确认后删除该程序的全部含义并移出程序列表。
- 编辑栏“指定程序”的候选：程序列表 + 当前情境程序 + “拾取窗口”。保存程序含义时自动把该程序加入程序列表。

### 5.6 执行：激活目标窗口

- 仅对**快捷键**动作生效（程序、文件夹、网址、工作流不受影响）。
- 开关“发送快捷键前激活光标下的窗口”开启（默认）且情境不是桌面时：
  1. 若情境窗口已是前台，直接发送；
  2. 否则激活情境根窗口（`SetForegroundWindow`；被前台锁拒绝时使用 `AttachThreadInput` 或补发一次 Alt 的常规做法），等待前台切换完成（最多约 150 ms），再发送；
  3. 激活失败：不发送，胶囊失败态“无法切换到 Chrome 窗口”，日志写明原因。
- 情境窗口以管理员身份运行而 PulseMouse 不是：右键和弦本来就放行（现状）；侧键与中键模式下胶囊提示“目标窗口以管理员身份运行，无法发送快捷键”，不静默失败。
- 关闭开关时恢复现状行为（发送给当前前台窗口）。

### 5.7 重复上一次（新动作类型）

- `ActionKind.Repeat = 5`，追加在现有枚举之后，旧值不变。
- 无目标字段。默认固定。
- 记录“上一次”：最近一次**成功执行**的节奏指令或手势，记下动作、情境进程名与窗口句柄。工作流和“重复上一次”本身不记录。
- 执行：
  - 上一次是快捷键：若原窗口仍存在，激活它后发送；原窗口已关闭则失败“原窗口已关闭”。
  - 其他类型：直接再执行一次。
  - 没有可重复的动作：失败“还没有可重复的动作”。
- 胶囊与最近执行显示“重复：粘贴”。统计同时计入“重复上一次”和被重复的指令。
- “上一次”只保存在内存中，不写入配置。

### 5.8 新含义提醒

- 替换型程序含义新建（含从模板添加）时 `RemindLeft = 5`；专属型为 0。
- 该含义每次成功执行后减 1，至 0 停止提醒。
- 提醒期间胶囊边框与情境行为琥珀色，情境行文案：“Excel 中 — 是新含义 · 全局是「关闭标签页」”，完成态停留约 2.2 s（普通 1.4 s）。
- 设置“新含义提醒”关闭时不显示，计数不变。

### 5.9 胶囊与犹豫提示

胶囊情境行（设置“胶囊显示当前程序”开启时）：

| 状态 | 情境行 |
|---|---|
| 等待 / 输入中、未匹配到完整节奏 | `[图标] Chrome · 3 个节奏有专属含义` 或 `全部沿用全局` |
| 匹配到程序含义 | `[图标] Chrome 中的含义` |
| 匹配到程序含义且提醒中 | `[图标] Excel 中 — 是新含义 · 全局是「关闭标签页」`（琥珀色） |
| 匹配到全局 | `全局 · 在 Excel`；固定的显示 `🔒 全局 固定 · 在 Excel` |
| 桌面 | 只显示 `全局` |

犹豫提示：标题“Chrome 中可用”；每行右侧标注 `[图标] 专属` / `[图标] 替换「复制」`（琥珀色）/ `🔒 固定` / 空（普通全局）。

关闭“胶囊显示当前程序”时，情境行恢复为现状的固定标题。

### 5.10 使用热度

- 每条指令按 Id 统计每日次数（沿用 `CommandsToday` / `History` 结构，键改为 Id）。
- 列表视图每行显示最近 7 天的小柱状图与合计次数，无使用显示“7 天未用”。
- 节奏地图每个格子右上角显示最近 7 天合计次数。
- 编辑栏显示 7 天柱状图（周几标签，最后一天为“今天”）与“上次 10:02 在 Chrome”。
- 热度只用于展示，v0.9 不做“长期不用建议删除”之类的提示。

### 5.11 模板（浏览器）

- 入口：指令库标题栏“从模板添加”。模板选择：浏览器（可用）、会议 · v0.10、演示 · v0.10（禁用）。
- 应用到：Chrome、Edge（进程 `chrome`、`msedge`）。
- 条目（名称 / 默认节奏 / 快捷键）：

| 名称 | 默认节奏 | 快捷键 |
|---|---|---|
| 后退 | `·—` | Alt+Left |
| 刷新 | `···` | F5 |
| 重新打开标签页 | `·——` | Ctrl+Shift+T |
| 前进 | `—·` | Alt+Right |
| 下一个标签页 | `—··` | Ctrl+Tab |
| 新标签页 | `·` | Ctrl+T |

- 每条状态与默认勾选：

| 状态 | 判定 | 默认 |
|---|---|---|
| 已添加 | 该程序已有同名同节奏含义 | 禁用 |
| 自动改用 | 默认节奏是固定节奏，或该程序已有其他含义占用 → 自动换成空闲节奏（规则同 5.4 推荐，且避开本次其他条目） | 勾选 |
| 替换全局 | 默认节奏是非固定全局指令 | **不勾选** |
| 空闲节奏 | 其余 | 勾选 |

- 分配顺序：先确定不需要改用的条目占用的节奏，再为“自动改用”条目依次分配。
- 添加后：程序加入程序列表；替换型条目 `RemindLeft = 5`；只添加绑定，不执行任何动作。

### 5.12 界面

#### 指令库

- 标题说明：“全局定义默认含义；每个程序可以把非固定的节奏改成自己的含义。”
- 标题栏按钮：从模板添加、新建指令（新建默认全局）。
- 工具栏：视图切换 节奏地图（默认）/ 列表。
  - 地图视图：图例（程序专属 / 替换了全局 / 固定）+ 添加程序。
  - 列表视图：搜索框（名称、快捷键、节奏前缀）。
- **节奏地图**
  - 行：所有 1–2 位节奏（6 个，始终显示，便于发现空闲的最短节奏）+ 任何已使用的更长节奏；排序同 5.2。
  - 列：节奏 | 全局 | 程序列表中的每个程序。每个程序列最小宽 150 px，超出时横向滚动。
  - 光标所在程序的列标题显示“● 光标”（实时跟随，只在主窗口可见时更新）。
  - 格子状态：

| 格子 | 样式 | 点击 |
|---|---|---|
| 全局有指令 | 名称 + 目标 + 7 天次数；固定的带锁 | 编辑该全局指令 |
| 全局空闲 | 淡色“+ 空闲” | 新建全局指令，节奏预填 |
| 程序含义（专属） | 薄荷色左边条 | 编辑 |
| 程序含义（替换） | 琥珀色左边条，副行“替换「X」” | 编辑 |
| 沿用全局 | 灰字“沿用 · X”，副行“点击改成 Chrome 的含义” | 新建该程序含义，节奏预填，类型沿用全局类型 |
| 固定 | 斜纹 + 锁 + “固定 · X”，鼠标为禁止 | 不进入编辑，提示“「X」已固定…可在全局指令里取消固定” |
| 程序空闲（全局也无） | “—” | 新建该程序含义 |

  - 当前编辑的格子有描边高亮。
  - “按程序切换含义”关闭时：地图顶部琥珀色提示条，程序格子半透明。

### 6.2 迁移（8 → 9）

1. 为每条指令生成 `Id`；`Scope = ""`；`Pinned` 按 5.3 规则计算；`PinnedManually = false`；`RemindLeft = 0`。
2. 统计键迁移：`CommandsToday` 与 `History[*].Commands` 中，名称**恰好对应一条**指令的改为该指令 Id；对应不到或重名的保留原键（展示时归入“已删除的指令”，不报错）。
3. `ContextApps` 为空。
4. 迁移前把原文件备份为 `settings.v8.bak.json`（同目录），迁移失败时保持原文件不动并提示。

### 8.2 真机验收（追加到 `docs/RELEASE_CHECKLIST.md`）

- 光标在 Chrome 上敲 `·—` 执行后退；在 Excel 上同节奏插入日期；在桌面上未匹配。
- 键盘焦点在 VS Code、光标在 Chrome 上敲“后退”：Chrome 被激活并后退，VS Code 不受影响。

- 添加 / 移除程序；移除后该程序回落全局。
- 关闭“按程序切换含义”后全部回落全局；重新打开恢复。
- 旧配置（v0.8）启动后自动迁移，6 条指令与统计保留，生成备份文件。
- 管理员窗口：和弦放行（现状）；侧键模式下快捷键失败有提示。

## 9. 已知限制（v0.9 接受）

- 网页应用与浏览器共用进程（例如网页版飞书与 Chrome 都是 `chrome.exe`），无法区分。后续可考虑按窗口标题细分。
- UWP 应用的进程可能是 `ApplicationFrameHost`，需要取子窗口的真实进程；若取不到，按 `ApplicationFrameHost` 处理并在添加程序时提示。
- 方向手势不区分程序。
- 激活窗口可能被某些全屏程序或系统前台锁阻止，此时失败提示而不是发错窗口。

## 10. 不在 v0.9 范围

- v0.10：系统麦克风静音与音量（真实状态）、开关类动作、全屏白名单（演示）、会议 / 演示模板。
- v0.11：节奏后用滚轮连续调节（音量等）、按程序映射滚轮。
- 不做：被替换全局含义的临时找回（停住切回 / Shift）、意图模型、热度驱动的删除建议、按窗口标题区分。
